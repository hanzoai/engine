# hanzo Python SDK

`hanzo` is the Python SDK for [hanzo](https://github.com/hanzoai/engine), a blazing-fast LLM inference engine.

## Documentation

For full documentation, see:
- [Python SDK Documentation](https://hanzoai.github.io/engine/tutorials/03-python-sdk/)
- [Installation Guide](https://hanzoai.github.io/engine/guides/install/)

## Quick Install

```bash
pip install hanzo-cuda   # NVIDIA GPUs
pip install hanzo-metal  # Apple Silicon
pip install hanzo        # CPU only
```
