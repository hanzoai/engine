Guides answer "how do I..." questions. They assume hanzo is installed. Otherwise, start with the [Tutorials](/hanzo/tutorials/).

## Choose by task

| If you need to... | Start here |
|---|---|
| Install for a specific platform or deployment target | [Install and deploy](/hanzo/guides/install/) |
| Run an HTTP server or web UI | [Serve models](/hanzo/guides/serve/) |
| Reduce memory use or improve throughput | [Performance](/hanzo/guides/perf/) |
| Add tools, search, code execution, or MCP | [Build agents](/hanzo/guides/agents/) |
| Use the Python package | [Python SDK](/hanzo/guides/python/) |
| Use the Rust crate | [Rust SDK](/hanzo/guides/rust/) |
| Work with vision, speech, image generation, or embeddings | [Model types](/hanzo/guides/models/) |
| Change model behavior or load adapters | [Customize](/hanzo/guides/customize/) |

## Guide sections

- [Install and deploy](/hanzo/guides/install/): platform-specific install steps, Docker images, and pre-production checks.
- [Serve models](/hanzo/guides/serve/): HTTP server configuration, multi-model serving, the web UI, and the OpenAI Responses API surface.
- [Performance](/hanzo/guides/perf/): quantization selection, the `tune` command, Flash and Paged attention, and multi-GPU or multi-machine splits.
- [Build agents](/hanzo/guides/agents/): tool calling, code execution, web search, MCP, and persistent sessions.
- [Python SDK](/hanzo/guides/python/): streaming completions, image and video input, and the multi-turn session API.
- [Rust SDK](/hanzo/guides/rust/): streaming and embedding hanzo in an Axum application.
- [Model types](/hanzo/guides/models/): vision input, image generation, speech, and embedding models.
- [Customize](/hanzo/guides/customize/): LoRA adapters, AnyMoE, MatFormer, sampling parameters, and TOML config.
